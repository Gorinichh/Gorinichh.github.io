ОБЩИЙ РЕГЛАМЕНТ

ЧИТАТЬ ПЕРВЫМ
Вы видите правила, студент видит устройство. Общаться — только голосом.
На устройстве 12:00. Каждая ошибка — штраф −1:00 и отметка. Три ошибки или ноль на таймере = отчисление. Когда все 5 заданий решены, студент нажимает «СДАТЬ РАБОТУ» на грани 01.
Порядок работы: 1) соберите паспорт (§01); 2) студент называет заголовки граней; 3) найдите каждое задание по номеру; 4) диктуйте по одному шагу и ждите подтверждения.
01

ПАСПОРТ УСТРОЙСТВА

СПРОСИТЬ ДО ВСЕГО
Слева внизу у студента есть «Паспорт устройства». Спросите и запишите:
▸ СЕРИЯ — две буквы, три цифры, буква (пример: КВ-417-Т). Гласные: А, Е, И, О, У, Ы.
▸ ВАРИАНТ — № 1–4.
▸ БАТАРЕИ — от 0 до 3 штук.
▸ ИНДИКАТОРЫ — какие из трёх горят: ЗВОНОК, РУЧКА, КОФЕ.
Эти четыре значения используются почти во всех тридцати правилах. Держите их перед глазами.
02

ПОИСК ЗАДАНИЯ

5 ИЗ 30
На коробке всегда 5 заданий из 30 возможных, в случайном наборе, на пяти гранях (передняя, правая, задняя, левая и верхняя). Каждая грань подписана: номер задания и название. Студент читает заголовок грани → вы находите в мануале задание с этим номером (01–30) → применяете правило. Не угадывайте: номера не совпадают с номерами граней.
I

ЗАДАНИЯ ВЫБОРА (01–07)

ГЛАВА
01«ВЫБОР ОТВЕТА»4 ЧИСЛА · А/Б/В/Г
ОПОЗНАНИЕ: четыре ответа с числами, подписаны А–Г. Посчитайте цифры серии: чётные и нечётные.
▸ Чётных больше → обвести наименьшее.
▸ Нечётных больше → обвести наибольшее.
▸ Поровну → обвести второй слева (Б).
02«СУММЫ»4 ЧИСЛА
ОПОЗНАНИЕ: просто четыре числа без подписей. Для каждого числа сложите его цифры (пример: 47 → 4+7 = 11).
▸ Вариант нечётный (1 или 3) → число с наибольшей суммой цифр.
▸ Вариант чётный (2 или 4) → с наименьшей.
При равенстве сумм — левое из них.
03«ЦВЕТНОЙ РЯД»4 ЦВЕТНЫЕ КНОПКИ
ОПОЗНАНИЕ: кнопки «красный / жёлтый / зелёный / синий». Смотрите только на число батарей:
0 батарей → жёлтый · 1 → красный · 2 → зелёный · 3 → синий.
04«ЧЁТНЫЙ РЯД»6 ЧИСЕЛ + ПРОВЕРКА
ОПОЗНАНИЕ: шесть чисел и кнопка «ПРОВЕРИТЬ». Студент должен отметить все числа той же чётности, что последняя цифра серии (последняя чётная → отметить все чётные; нечётная → все нечётные), и только их. Пропуск или лишнее = ошибка. После ошибки отметить заново всё.
05«БУКВЫ»4 БУКВЫ
ОПОЗНАНИЕ: четыре буквы. Посчитайте гласные буквы в серии.
▸ Гласных 0 или 1 → среди четырёх нажмите гласную (она там одна).
▸ Гласных 2 или 3 → нажмите согласную (она там одна).
06«ДРОБИ»4 ДРОБИ
ОПОЗНАНИЕ: четыре дроби вида 3/4. Два шага, строго по порядку:
1) Если индикатор КОФЕ горит → рассматриваем только дроби больше 1 (числитель больше знаменателя). Если КОФЕ не горит → только меньше 1.
2) Из оставшихся двух: вариант чётный → меньшую по значению; вариант нечётный → большую.
07«РИМСКИЕ ЧИСЛА»4 РИМСКИХ ЧИСЛА
ОПОЗНАНИЕ: IV, XXIII, LXXVII и т.п. Переведите в обычные числа (I=1, V=5, X=10, L=50; IV=4, IX=9, XL=40).
▸ Первая цифра серии чётная → выбрать наименьшее.
▸ Нечётная → наибольшее.
II

ПРОВОДА И ЦЕПИ (08–10)

ГЛАВА
Цвета проводов: красный, жёлтый, синий, зелёный, белый. Всегда диктуйте по одному проводу.
08«ЭЛЕКТРИЧЕСКАЯ ЦЕПЬ»5 ПРОВОДОВ
ОПОЗНАНИЕ: надпись «ЗАЧЁРКИВАТЬ МАРКЕРОМ». Смотрите на последнюю цифру серии.
▸ Чётная → зачеркнуть тёплые: красный и жёлтый.
▸ Нечётная → холодные: синий и зелёный.
Белый не трогать никогда. Порядок любой.
09«ПОРЯДОК РЕЗКИ»5 ПРОВОДОВ · ПО ОЧЕРЕДИ
ОПОЗНАНИЕ: наклейка «ПОРЯДОК ЕСТЬ ДИСЦИПЛИНА». Здесь важен порядок. Найдите столбец варианта в таблице и диктуйте по одному:
ШАГВАР. 1ВАР. 2ВАР. 3ВАР. 4
1-йбелыйкрасныйзелёныйжёлтый
2-йкрасныйжёлтыйсинийзелёный
3-йсинийзелёныйбелыйкрасный
4-йжёлтыйсинийкрасныйбелый
5-йзелёныйбелыйжёлтыйсиний
Ошибка сбрасывает прогресс: начинать заново с 1-го шага.
10«СИЛОВАЯ ЦЕПЬ»5 ПРОВОДОВ · ОДИН НЕ ТРОГАТЬ
ОПОЗНАНИЕ: упоминание «несущего провода». Несущий провод — провод цвета вашего варианта (см. Приложение А). Его трогать нельзя. Зачеркните все остальные четыре, порядок любой.
III

КОДЫ И ШИФРЫ (11–13)

ГЛАВА
11«КОД ДОСТУПА»4 ЦИФРЫ · КЛАВИАТУРА
ОПОЗНАНИЕ: экран на 4 клетки и клавиатура. ФОРМУЛА 11 — четыре цифры:
1-я — число гласных букв в серии;
2-я — вариант × 2 (если ≥ 10 — последняя цифра);
3-я — последняя цифра серии;
4-я — если КОФЕ горит: последняя цифра суммы (1-я + 3-я); иначе — 7.
12«КОРОТКИЙ КОД»3 ЦИФРЫ
ОПОЗНАНИЕ: экран на 3 клетки. ФОРМУЛА 12:
1-я — (батареи + гласные), последняя цифра;
2-я — последняя цифра серии;
3-я — (вариант × последняя цифра), последняя цифра.
13«ЗЕРКАЛЬНЫЙ КОД»ШИФРОГРАММА + КЛАВИАТУРА
ОПОЗНАНИЕ: на грани написаны 4 цифры-шифрограмма. Студент диктует шифрограмму. Дальше решает индикатор РУЧКА:
▸ РУЧКА горит → вводим цифры шифрограммы в том же порядке, каждую +1 (9 превращается в 0).
▸ РУЧКА не горит → вводим шифрограмму задом наперёд.
IV

ТУМБЛЕРЫ И РЕГУЛЯТОРЫ (14–17)

ГЛАВА
14«ПЯТЬ ТУМБЛЕРОВ»5 ТУМБЛЕРОВ + ПРОВЕРКА
ОПОЗНАНИЕ: ряд из пяти тумблеров, считая слева — биты 1–5. ФОРМУЛА 14: N = (сумма цифр серии × вариант), последние 5 бит (N по модулю 32). Переведите N в двоичный код из 5 бит: 1-й тумблер — старший бит, вверх = 1, вниз = 0. Пример: сумма 12, вариант 3 → 36 → по модулю 32 = 4 → 00100 → вверх только 3-й тумблер. Затем «ПРОВЕРИТЬ».
15«ТРИ ТУМБЛЕРА»3 ТУМБЛЕРА + ПРОВЕРКА
ОПОЗНАНИЕ: три тумблера. Тумблер №i — вверх, если i-я цифра серии нечётная, и вниз, если чётная. Затем «ПРОВЕРИТЬ».
16«КРУТИЛКА»ЦИФЕРБЛАТ 0–7 + ⟲ ⟳ + ГОТОВО
ОПОЗНАНИЕ: круглая ручка с цифрами 0–7. Целевая цифра = (сумма цифр серии + батареи), последняя цифра результата… и ещё раз: если вышло больше 7 — вычесть 8. Студент крутит кнопками ⟲/⟳ до этой цифры и жмёт «ГОТОВО».
17«РЫЧАГ»4 ПОЗИЦИИ
ОПОЗНАНИЕ: рычаг с гнёздами 1–4. Цепочка: возьмите номер варианта. Если ЗВОНОК горит — прибавьте 1. Если КОФЕ горит — прибавьте ещё 1. Если вышло больше 4 — вычитайте 4. Перевести рычаг в полученную позицию.
V

КНОПКИ И УДЕРЖАНИЕ (18–20)

ГЛАВА
18«КНОПКА С ЛАМПОЙ»КРАСНАЯ КНОПКА + ЛАМПА
ОПОЗНАНИЕ: наклейка «РАНЬШЕ ВРЕМЕНИ НЕ ОТПУСКАТЬ». Студент нажимает и держит кнопку — лампа начнёт переключать цвета. Командуйте «ОТПУСКАЙ», когда лампа горит цветом варианта (Приложение А). Держать меньше полусекунды — ошибка.
19«СЧЁТ ВСПЫШЕК»СИНЯЯ КНОПКА + ЛАМПА
ОПОЗНАНИЕ: синяя кнопка «ДЕРЖАТЬ». ФОРМУЛА 19: N = вариант + (КОФЕ горит ? +2 : 0) + (ЗВОНОК горит ? +1 : 0). Студент держит кнопку, лампа мигает, вы оба считаете вспышки ВСЛУХ. Командуйте «ОТПУСКАЙ» сразу после N-й вспышки.
20«ДВЕ КНОПКИ»ЛЕВАЯ / ПРАВАЯ
ОПОЗНАНИЕ: всего две кнопки. ▸ Гласных букв в серии чётное число (0 или 2) → левая; нечётное → правая.
▸ Подвох: если ЗВОНОК горит — ответ меняется на противоположный.
VI

ЛОГИКА И НАБЛЮДЕНИЕ (21–30)

ГЛАВА
21«СРАВНЕНИЕ»X, Y И ЗНАКИ > < =
ОПОЗНАНИЕ: два числа на грани. Определите настоящее соотношение X и Y. Затем: если индикатор РУЧКА горит, знаки > и < меняются местами (= не меняется). Нажмите итоговый знак.
22«АЗБУКА МОРЗЕ»ЛАМПА ВЫСТУКИВАЕТ БУКВУ
ОПОЗНАНИЕ: подпись «ПЕРЕДАЧА», четыре варианта букв. Лампа по кругу выстукивает одну букву: точка — короткая вспышка, тире — длинная. Расшифруйте по Приложению Б и нажмите эту букву.
23«ПОВТОРИ ВСПЫШКИ»ПЛАШКА + 4 ЦВЕТНЫЕ КНОПКИ
ОПОЗНАНИЕ: плашка-экран и кнопки КРАСНЫЙ/ЖЁЛТЫЙ/ЗЕЛЁНЫЙ/СИНИЙ. Устройство покажет 4 вспышки подряд. Запомните их. Нажимать нужно не то, что показано:
СКОЛЬКО ОШИБОК УЖЕ ЕСТЬСДВИГ
0нажимайте показанный цвет
1цвет +1 шаг вперёд по кругу
2цвет +2 шага вперёд по кругу
Круг цветов: красный → жёлтый → зелёный → синий → снова красный. Пример: показан жёлтый, ошибок уже 1 → нажимать зелёный.
24«СИМВОЛЫ»4 СИМВОЛА
ОПОЗНАНИЕ: странные значки (Ω, Ψ, ∆, λ, Σ, §, Ж, Ф). Порядок нажатия задаёт строка из Приложения В. Строку выбирайте по числу гласных в серии: 0–1 → строка I; 2 → строка II; 3 → строка III. Нажимайте показанные символы в порядке их появления в строке.
25«КОСТИ»ДВА КУБИКА + 4 ЧИСЛА
ОПОЗНАНИЕ: пиктограммы кубиков. Правила проверяются строго по порядку, первое подошедшее побеждает:
1) Если на кубиках одинаковые числа → ответ = их произведение.
2) Иначе, если вариант чётный → ответ = сумма.
3) Иначе → ответ = разность (из большего вычесть меньшее).
26«КАМЕНЬ–НОЖНИЦЫ–БУМАГА»3 КНОПКИ
ОПОЗНАНИЕ: кнопки КАМЕНЬ/НОЖНИЦЫ/БУМАГА. Устройство отвечает случайно после вашего хода.
▸ Вариант нечётный → студент обязан ВЫИГРАТЬ раунд.
▸ Вариант чётный → обязан ПРОИГРАТЬ.
Ничья всегда ошибка. Камень бьёт ножницы, ножницы — бумагу, бумага — камень.
27«ЛАМПЫ ДА/НЕТ»2 ЛАМПЫ + ДА/НЕТ
ОПОЗНАНИЕ: вопрос про чётность варианта. Вопрос всегда один: «Номер варианта — чётное число?» Сначала смотрите на лампы:
▸ Горят обе лампы → отвечайте наоборот.
▸ Во всех остальных случаях → отвечайте правду.
28«ЦИФРЫ ПО ПОРЯДКУ»КНОПКИ С ЦИФРАМИ СЕРИИ
ОПОЗНАНИЕ: кнопки с цифрами из серии. Направление зависит от последней буквы серии:
▸ Последняя буква гласная → нажимать цифры по убыванию.
▸ Согласная → по возрастанию.
Повторяющиеся цифры считаются один раз.
29«ГИРЛЯНДА»5 ЛАМП + ПРОВЕРКА
ОПОЗНАНИЕ: пять переключаемых ламп. Правило для каждой лампы, слева направо:
1-я — горит, если 1-я цифра серии чётная.
2-я — горит, если 2-я цифра чётная.
3-я — горит, если 3-я цифра чётная.
4-я — горит, если КОФЕ горит.
5-я — горит, если вариант чётный.
Затем «ПРОВЕРИТЬ».
30«АРИФМЕТИКА»ПРИМЕР СО ЗНАКОМ + КЛАВИАТУРА
ОПОЗНАНИЕ: пример вида A ▲ B, A ■ B или A ● B. Значки операций: ▲ = сложение, ■ = вычитание, ● = умножение. Посчитайте результат и продиктуйте; отрицательных результатов не бывает. Подтверждение — кнопка «ОК».
